# 独立视线预测

打开应用并开启摄像头，点击「开始视线预测」。模型在浏览器内加载，无需启动
情绪识别后端。视线预测和情绪/眨眼识别共用 Monitor 持有的 MediaStream 与 video，
各自独立启停；关闭摄像头会停止两条流程并清除视线校准。

## 校准及验证

1. 若需要覆盖整个显示区域，先点击「切换全屏」。
2. 点击「开始视线校准」，保持头部、座位和照明稳定。
3. 按顺序注视 16 个点，每点点击 5 次；移到新目标后等待至少 0.5 秒。
   只有新取得的、300 ms 内的有效眼部样本才计数。鼠标只是校准确认输入。
4. 校准结束后自动显示 5 个独立验证点，每个注视 3 秒，无需点击。
   每点前 0.8 秒留给视线移动，剩余时间采集真实预测。验证样本不参与训练。
5. 显示平均欧氏距离误差（CSS 像素）和有效采样率。任一点不足 3 个有效
   样本时不显示误差数值。该结果不是医学精度或走神分类准确率。

窗口尺寸、全屏状态改变会使校准失效。暂停保留已完成的校准；校准中断需要
重做。浏览器刷新不恢复旧样本。头部位置明显改变后应手动重新校准。

## 数据与边界

`GazePoint` 提供 x/y、normalizedX/Y、viewportWidth/Height、timestamp
及 inViewport；无有效预测时 `frame.point` 为 null。x/y 为网页可视区域的
CSS 像素，原点在左上角，不是操作系统桌面坐标，也不是摄像头图像坐标。
归一化坐标按视口宽高计算，区域外预测保留原值，不截断伪装成边缘落点。
界面和对外结果使用同一滤波坐标。标记不拦截事件，不控制鼠标、不自动点击。

摄像头原始帧不镜像地送入 FaceMesh 和眼部裁剪；已有预览的 CSS 镜像只影响显示。
视线功能不上传或持久化画面、眼部样本与坐标，不自动调用走神分类器。
普通摄像头的实际误差依赖个人、光照和头部姿态，需真人校准验证。

## 实现与部署

- `web-react/src/features/gaze/core` 提取 WebGazer 灰度眼部图像特征和加权岭回归。
- `web-react/src/features/gaze/services/gazeService.ts` 负责本地 FaceMesh、单次串行推理、校准及资源释放。
- `web-react/src/features/gaze/hooks/useGazePrediction.ts` 管理独立状态、旧结果失效及 React 生命周期。
- 首次启用才加载算法模块和本地模型，无额外 npm/Python 依赖。
- `public/mediapipe/face_mesh` 随 Vite 构建进入 dist；FastAPI 托管 `/mediapipe`。
- 浏览器需支持摄像头、WebAssembly 和 WebGL，通过 localhost/127.0.0.1 或 HTTPS 使用。

原项目仍保留作参考，应用不引用其演示入口。来源、许可证及改动见 core/README.md。
