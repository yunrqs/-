# 监测 API

基础地址：http://127.0.0.1:8001 。接口与重构前保持一致。

| 方法 | 路径 | 功能 |
| --- | --- | --- |
| GET | /api/health | 返回 ok 和模型 ready 状态 |
| POST | /api/session/start | 加载模型、启动识别会话 |
| POST | /api/session/reset | 重置眨眼、情绪历史及帧统计 |
| POST | /api/analyze | multipart/form-data 的 frame 字段上传图片 |

图像上限仍为 5 MiB。缺失、空或损坏图片返回 400，超限返回 413，模型未就绪返回 409。
模型加载、重置或分析异常返回 500，错误说明在 detail 字段。
分析返回尺寸、人脸位置、EAR、阈值、眼部状态、眨眼次数与频率、有效人脸比例及情绪概率。
健康、启动、重置接口的字段和分析响应字段未改名。
当前接口不提供走神分类；离线 MWDET 分类模型仍使用独立特征输入。
